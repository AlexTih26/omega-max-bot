# Этап 6 новой Таксимо: история блока и машины (коммит 5f49e08)

Ветка `kodik/new-taksimo-integration`. Миграция `013` **применена**.
Рабочая база: 14 миграций.

## Главная идея

У **блока** есть паспорт с идентификатором от рождения. Один физический блок,
попавший в разные рейсы, остаётся **одной** записью паспорта. Поэтому история
рейса, машины и вагона — это по сути история перемещений блоков.

## Ключ блока

`_block_key(letter, number)` → `"A-901"`: буква верхним регистром, дефис,
номер без пробелов, тоже верхним регистром. Буква проверяется по `ABCDEFK`,
иначе `ValueError`. Номер длиннее 78 символов отклоняется.

`store._block_key("a", " 901 ")` == `store._block_key("A", "901")` == `"A-901"`.

## Таблицы (миграция 013)

- `tn_block_registry` — паспорт: `block_key` UNIQUE, буква, номер, суффикс,
  вес, цена, `state` (`declared/in_transit/at_yard/in_wagon/in_kodar/
  unloaded_bts_east/returned`), `first_trip_id`, `first_account_id`.
- `tn_block_history` — события перемещений: `event_type`, `location_kind`,
  `trip_id`, `wagon_number`, `yard_x/y`, `details_json`, актор, `occurred_at`.
  `ON DELETE RESTRICT`: подтверждённую историю не удаляют.
- `tn_trip_blocks.registry_block_id` и `tn_blocks.registry_block_id` — связь
  строк с паспортом.
- Индексы `tn_trips` по машине+дате для истории машины.

## Функции store (в конце taksimo_new_store.py)

`_block_key`, `_ensure_block_registry`, `_append_block_history`,
`register_trip_blocks`, `block_history`, `list_blocks`, `vehicle_history`,
`list_vehicles`.

Правила:
- вес и цена паспорта **не перезаписываются**, если уже заданы;
- `register_trip_blocks` идемпотентен: повторно не дублирует паспорт и не
  добавляет второе событие `trip_declared` по тому же рейсу;
- при регистрации состояние паспорта переходит `declared → in_transit`;
- `vehicle_history` принимает id или госномер, `trip_count` — ответ на
  «сколько раз сходила машина»;
- `list_blocks` и `list_vehicles` отдают `trip_count` подзапросом.

## API

```
GET /api/taksimo-new/blocks?q=&state=&limit=
GET /api/taksimo-new/blocks/{block_key}/history
GET /api/taksimo-new/vehicles?q=&limit=
GET /api/taksimo-new/vehicles/{vehicle_ref}/history
```

История доступна всем вошедшим. `POST /trips` теперь **сразу** вызывает
`register_trip_blocks`.

Коды ошибок: несуществующая буква (`Z-999`) → 400 «Некорректно указан ключ»;
существующая буква с несуществующим номером (`A-999`) → 404.

## Фронтенд

Вкладка `data-tab="history"` («История», после «Поиска»), без ролевых
атрибутов. Поиск, переключение «Блоки/Машины», карточки и панель
подробностей. Всего **14 вкладок = 14 панелей**.

## Проверено на живой базе

Блок `A-901` прошёл два рейса — паспорт один, `trip_count=2`. Четыре паспорта
на шесть строк блоков. Вес 7780 сохранился из справочника. Машина К123МН75:
«сходила 2 раза». 78 тестов новой Таксимо зелёные.

Тестовые данные удалены; активны операторы 1-3 и **админ** (владелец завёл
его сам, проверяя вход).
