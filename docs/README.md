## Как добавить новую инструкцию

1. Положить текст в `docs/` в формате markdown.
2. Добавить строку в таблицу выше.
3. Пересобрать страницы для телефона:

```
python3 scripts/build-sklad-help.py
```

Markdown в `docs/` остаётся источником: правки вносятся туда, страницы `web/*.html` пересобираются одной командой.
