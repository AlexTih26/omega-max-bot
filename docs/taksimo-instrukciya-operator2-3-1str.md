## Права

✅ Выгрузка · плиты · план · вагоны · поиск · журнал · Excel · правка · черновик · завершение  
❌ **Удалить** выгрузку или плиту — **серые кнопки** → только **оператор 1**

---

## Приём машины

1. **Тап по машине** (обязательно!)
2. Дата · ТРН · водитель
3. Плиты: **буква · номер · X/Y** (если **ХРАНЕНИЯ**)
4. **Черновик** — пока принимаете (чат молчит)
5. **Кран с / до** — перед завершением (*)
6. **Завершить приём** — машина принята → через ~1 мин сообщение в чат водителей

| Статус | X/Y | Когда |
|--------|-----|-------|
| **ХРАНЕНИЯ** | да, 1…13 / 1…25 | блок на складе |
| **В ПУТИ** | нет | едет |
| **ГРУЗОВОЙ / ТУРАН** | нет | в вагон (вагон на «Плане») |

---

## План (13×25)

- X справа→налево · Y ряд 1…25 · **макс. 4 блока/ячейка**
- Курсор в **X или Y** → вкладка **План** → **тап по ячейке**
- **Тупики:** тап слот → вагон · **макс. 9** блоков/вагон · зелёный = комплект совпал

## Журнал · ошибки

- **Журнал** → строка → **Редактировать** (удаление — оператор 1)
- «Нажмите машину» → выберите карточку
- «Максимум 4 плиты» → другая ячейка
- Два оператора — **разные машины**, не одна выгрузка

**PIN и удаление → оператор 1**
