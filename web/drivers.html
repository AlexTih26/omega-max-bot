Журнал

    За 7 дней записей нет — отметьте рейс на вкладке «Мой рейс».

    Откройте через кнопку «Открыть панель» в чате водителей MAX.

    1. Прибыл на завод — нажмите сами. Может отметить и Румекс.

    2. Выехал с завода — нажмите сами или ждите Румекс после документов.

    3. Прибыл в Таксimo — нажмите сами или отметит оператор при начале приёмки.

    4. Выехал с площадки — само, через ~5 мин после приёмки. Кнопки нет.

    Чат водителей — одна строка на событие. Не пишите в чат — только смотрите.

    Мой журнал — ваши рейсы за 7 дней, не весь парк.

    Регистрация. Нажмите кнопку — диспетчер Румекс добавит вас в реестр по вашему MAX id.

    Рейс. Завод → выезд → Таксimo → выезд с площадки (последний сам, без кнопки).

    Чат. Только уведомления для всех водителей — не пишите туда.
